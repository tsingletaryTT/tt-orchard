🔑 Key Insights

  • All model tiers have identical context windows (256K), making them interchangeable for the supervisor's purposes.
  • Agent responses are limited to 6.25% of model capacity - the 16K token budget is designed to keep agent turns focused and prevent runaway reasoning loops.
  • Canary checks use just 64 tokens - enough for a short answer to questions like "What is 7 times 6?" without room for elaborate reasoning.
  • The 16K agent budget was chosen because at ~80 tokens/second, a full response takes about 200 seconds, which is manageable for agent coordination.

Scale Illustration

Imagine the model context window is a 262-meter building:

  • Agent Budget (16K): A 16-meter tall section - substantial, but clearly bounded

This illustrates why the supervisor needs strict turn limits: without them, agents could consume the entire context window in a single turn.

📈 Summary

The tt-orchard system uses 256K context windows for all model tiers (Large, Small, and CPU), but constrains agent responses to 16K tokens (6.25%) to prevent runaway reasoning loops. Canary checks use just 64 tokens (0.025%) for quick sanity checks.

This design ensures agents can do substantial reasoning while remaining manageable and predictable in their resource consumption.
