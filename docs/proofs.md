# What has been shown, and what has not

This page lists each claim the README makes about tt-orchard, the evidence for it, and where that evidence is. Every measurement came from one
QuietBox 2 (two p300c boards, four Blackhole chips). Numbers are single runs unless a row says otherwise. `CLAUDE.md` holds the dated log entry
for each item; the run logs under `docs/run-logs/` hold the longer write-ups.

## Shown on real chips

## Shown only with fakes, or by one hand-run

- The graft trial inside the supervisor (the hand experiment is above).
- The `bus` preflight row on a failed board (only a healthy box was available).
- The 4-chip stage 2's retry path (the first attempt blocked and was resumed by hand; the retry passed).

## Not shown

- A model that needs new model code going through the full-port stages without a helper: the coder alone failed stage 2 in runs 18, 20 and 24 of the tiny Qwen4 rehearsal. Issue 61 is out of date; two models have passed with the helper.
- A controlled comparison of the coder alone with and without the stage tools and the decoder idioms file. The stage tools were already available in run 20 (where `edit` and `layer-diff` went unused) and the idioms file (PR 575) merged before run 24's recorded failure, so the three coder-alone failures do not isolate their effect.
- QSA on a real model: not shown. The Qwen3.8-27B-QSA bring-up ended blocked at stage 5 (stage-failed after escalation, 2026-11-08 23:40Z). Stages 0 to 4 passed on four chips. Stage 5 serving matched the reference on all 80 corpus positions. The passkey check failed at both lengths (256 and 8,192 tokens) because a thinking model's reply was cut at the answer limit before a key appeared (issue 641). Separately, QSA was not shown working: the stage 2 port does not use the `_qsa_indexer` tensors and every agreement prompt is shorter than the 2,048-token budget, so the indexer was not exercised (issue 638).
- A run from start to end with nobody touching the machine. The latest ones needed a person for disk space or for a restart.
- A fidelity bar measured from controls: the prompt suite and the 32-token check use choices (issue 15).
- Long-context behaviour (issue 18), agent-style benchmarks (issue 21), 4-chip packages from the harness, and 1-chip packages for the later models (issue 23). 1-chip packages were staged and booted from local copies only for Hemmingway-1 and openthai.
- Any machine other than the development QuietBox 2.
- A container-only package that actually serves swapped weights (issues 60 and 68), and a quantized copy of a supported model (issue 63).

The open issues are the list of what is next: <https://github.com/tsingletaryTT/tt-orchard/issues>.
