## Pass thresholds (written before any measurement of this package)

Anchors: the published Olmo-Hybrid-7B package (served decode median 7.28 tok/s, min 3.59, max 9.30 over 15 runs, same kind of port: no key-value cache, host-side
token choice, four chips; its stage 6 agreement was top-1 1.0 over 32 tokens on one prompt), and this run's own stage 6 record (decode median 8.32 tok/s, top-1
0.96875 over 32 tokens, passkey 256 and 8192 passed in stage 5). The bars below are for the served bundle.

Publish only if every row of the first table passes. The second table is measured and put on the card without a bar.

| id | bar | how it is measured |
| --- | --- | --- |
| A1 | teacher-forced top-1 agreement with the transformers CPU reference at least 0.95 over at least 600 positions | 6 prompts (4 plain, 2 in the chat format), 128 reference tokens each, the reference's own continuation fed in; port logits vs reference logits |
| A2 | passkey found at prompt lengths of about 256, 2048 and 8192 tokens, through the served bundle | one fixed passkey prompt per length, greedy |
| A3 | 5 of 5 short chat questions answered with the expected fact (substring check) through the chat route | served bundle, greedy |
| P1 | served decode rate at short context: median at least 7.0 tok/s over at least 15 runs (anchor: Olmo-Hybrid-7B's 7.28 median, a 3x larger model) | `scripts/aion/bench.py`, warm kernel cache, host load recorded |
| P2 | prefill of a prompt of about 2048 tokens at most 10 s, and a prompt of about 8192 tokens completes without error | same script |
| G1 | `tt-orchard can gate` passes with `card_profile = "catalog-measured"` and the boot check (`can boot`) passes | the can commands |

| id | measured, no bar |
