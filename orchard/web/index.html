    How to turn it on

    Telegraph is off unless the bringup config has a [telegraph] table with enabled = true, an endpoint, a list of models, and a key from a variable (key_env) or a file (key_file). Add caps (max_calls, max_total_tokens, max_cost_usd with prices) so the spend stops by itself. The full list of settings and the commands are in README section 5.9g. The page reads the config when it starts and after a save on the Models view, so restart tt-orchard ui after you edit the file. The meter then shows the new state.

    The meter is always on screen: in the top bar, and pinned along the bottom edge on screens up to 900 px wide. Amber means a cap is at 80 percent or more. Red means a cap is used up or the latest call was refused; the reason is in the meter.
